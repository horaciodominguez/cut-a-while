# Cut a While v0.1.6

Stats, settings, and the idle clock now match what they say.

## Highlights

- Changing Work while idle or stopped updates the clock. Sliders save on release and apply to the next session
- **Show Statistics** opens the drawer even if the panel was just created
- Week matches the last 7 days. Today shows its minutes
- Settings hints for Auto-start, Auto-pause, the long-break interval, and Zen mode
- Header icons close the open drawer. The green accent is no longer the break color

See [CHANGELOG.md](./CHANGELOG.md) for the full list.

## Install

Download `cut-a-while-0.1.6.vsix` from this release, then **Extensions → … → Install from VSIX…**.

Or update from VS Marketplace / Open VSX when the listing shows 0.1.6.
