# Cut a While v0.1.4

Discovery and task-flow polish, plus host stability from the P2 pass.

## Highlights

- Activity Bar is an overview: **Open Timer Panel** and Start / Pause live in the tree and the view title
- Task chips select a task; **Start** begins the session; the task stays editable while focusing
- Mac shortcut `Cmd+Shift+T`
- Clearer keyboard access for deleting tasks and announcing phase changes
- Windows beeps no longer pile up; extension listeners are disposed cleanly

See [CHANGELOG.md](./CHANGELOG.md) for the full list.

## Install

Download `cut-a-while-0.1.4.vsix` from this release, then **Extensions → … → Install from VSIX…**.

Or update from VS Marketplace / Open VSX when the listing shows 0.1.4.
