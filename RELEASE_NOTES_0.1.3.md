# Cut a While v0.1.3

UX and accessibility improvements on top of the 0.1.2 timer stability release.

## Highlights

- Safer Zen Mode (exits on pause/break without re-toggling)
- Accessible drawers (Escape, focus trap, reduced motion)
- Settings sync with VS Code + aligned slider ranges
- Session dots follow your long-break interval
- Stop / Reset confirmations via native VS Code modals
- Windows sound preview matches completion beeps
- Settings drawer scroll / scrollbar polish

See [CHANGELOG.md](./CHANGELOG.md) for the full list.

## Install

Download `cut-a-while-0.1.3.vsix` from this release, then **Extensions → … → Install from VSIX…**.

Or update from VS Marketplace / Open VSX when the listing shows 0.1.3.
