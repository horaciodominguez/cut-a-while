# Cut a While v0.1.7

Quieter controls and less leftover chrome.

## Highlights

- Status bar click starts or pauses. Stop shows the next focus length
- A paused break keeps Resume, Stop, and Start next focus
- Completion toast only when the timer panel is hidden
- Auto-pause asks once; dismissing leaves the timer paused
- Activity Bar is Open + Today. Status bar alignment is in Settings
- Removed unused file-focus hover and the unused streak panel field

See [CHANGELOG.md](./CHANGELOG.md) for the full list.

## Install

Download `cut-a-while-0.1.7.vsix` from this release, then **Extensions → … → Install from VSIX…**.

Or update from VS Marketplace / Open VSX when the listing shows 0.1.7.
